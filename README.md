# Lab 6 — Secure TLS Client–Server Application

Лабораторна робота №6.
Розробка безпечного клієнт-серверного
застосунку з використанням SSL/TLS.

## Функціональні можливості

- Захищений обмін повідомленнями через TLS 1.2 та TLS 1.3.
- Локальний центр сертифікації та перевірка сертифікатів.
- Опціональна взаємна автентифікація mTLS.
- Автентифікація користувачів через bcrypt.
- Сесійні токени та контроль доступу.
- Двостороння перевірка цілісності HMAC-SHA256.
- Перевірка порядкових номерів повідомлень.
- Валідація JSON та обмеження розміру даних.
- Структуроване журналювання JSONL.
- Виявлення повторюваних невдалих автентифікацій.
- Автоматизоване тестування механізмів захисту.

## Середовище виконання

- Kali GNU/Linux Rolling 2026.3
- Python 3.14.7
- OpenSSL 3.6.3
- bcrypt 5.0.0
- Git 2.53.0
- VirtualBox
- Wireshark / tcpdump

## Встановлення

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m pip check
```

## Ініціалізація сертифікатів та конфігурації

```bash
bash scripts/gencerts.sh
python scripts/init_config.py
```

Під час ініціалізації необхідно встановити пароль
тестового користувача alice.

Сертифікати та секрети генеруються локально
і не входять до репозиторію.

## Запуск сервера

У першому терміналі:

```bash
source .venv/bin/activate
python server.py
```

Сервер прослуховує 127.0.0.1:8443.

## Запуск клієнта

У другому терміналі:

```bash
source .venv/bin/activate
python client.py --user alice --msg "Hello Secure TLS"
```

Пароль вводиться приховано.

## Перевірка TLS 1.2 і TLS 1.3

```bash
python client.py --tls 1.2 --user alice
python client.py --tls 1.3 --user alice
```

## Режим mTLS

Зупинити звичайний сервер та запустити:

```bash
python server.py --require-client-cert
```

Клієнт:

```bash
python client.py --tls 1.3 \
    --cert certs/client.crt \
    --key certs/client.key \
    --user alice
```

## Автоматизоване тестування

Запустити сервер у звичайному режимі TLS,
без обов'язкового клієнтського сертифіката.

У другому терміналі:

```bash
python -m unittest discover -s tests -v
```

Під час запуску тестів необхідно ввести
правильний пароль користувача alice.

## Аналіз журналів

python analyze_logs.py

## Підтверджені результати

- 12 із 12 автоматизованих тестів пройдено.
- TLS 1.2 та TLS 1.3 працюють коректно.
- TLS 1.1 та незашифровані запити відхиляються.
- Недовірені сертифікати відхиляються.
- Некоректні токени та HMAC відхиляються.
- Повторні повідомлення в межах сесії відхиляються.
- Аномалію автентифікації успішно виявлено.
- Підтверджено працездатність mTLS.
- Контрольне повідомлення у захопленому трафіку
  у відкритому вигляді не виявлено.

## Обмеження

Проєкт призначено для локального навчального середовища.
Сервер обслуговує з'єднання послідовно.
Максимальний розмір корисних даних становить 4096 байтів.

HMAC-ключ спільний для лабораторного клієнта та сервера.
mTLS не прив'язує сертифікат до конкретного користувача.

Аналізатор виявляє повторні невдалі входи,
але автоматично не блокує користувачів.
Локальні журнали не мають криптографічного захисту
від модифікації власником.

Для промислового використання потрібні додаткові
заходи захисту, масштабування та незалежний аудит.
